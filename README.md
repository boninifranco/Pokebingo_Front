# 🎮 Pokebingo – Frontend

Frontend de **Pokebingo**, aplicación de bingo con temática Pokémon.  
Construido en **React**, ofrece la interfaz de usuario para interactuar con el juego: cartones, partidas en tiempo real.

---

## ✨ Características principales

- 🎲 Sala de juego con cartones de bingo con temática Pokémon y chat incluido en tiempo real (via **socket.io-client**).
- 👥 Gestión de usuarios y partidas. 
- 💳 Integración de pagos con **MercadoPago SDK**.  
- 🎨 UI basada en **Bootstrap** y **React-Bootstrap**.  
- 🔀 Navegación con **React Router DOM**.  
- 🧪 Testing con **Jest**.

---

## 🚀 Instalación y ejecución local

```bash
# Clonar el repositorio
git clone https://github.com/boninifranco/Pokebingo_Front.git

# Entrar en la carpeta del proyecto
cd Pokebingo_Front

# Instalar dependencias
npm install

# Correr la app en desarrollo
npm start

# Abrir en el navegador (generalmente en http://localhost:3000)
